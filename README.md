# Velocity · Claude Code marketplace

The official AiCoaches marketplace for [Velocity](https://velocity.forum)
Claude Code tooling.

## Plugins

### `velocity-receipts`
Records Velocity skill invocations in Claude Code so Value Impact
compounds across your real work.

```
claude plugin marketplace add aicoachesdotcom/velocity-claude-plugin
claude plugin install velocity-receipts@aicoaches
```

See [`plugins/velocity-receipts/README.md`](./plugins/velocity-receipts/README.md).
